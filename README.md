# Jarvis – Web-Based Voice Assistant

## Project Overview

Jarvis is a browser based voice assistant developed using modern web technologies. It enables users to interact with a system through natural voice commands, providing real-time responses and automating web-based tasks such as searching, navigation, and information retrieval.
This project demonstrates practical implementation of speech recognition, speech synthesis, and event-driven programming in a user-friendly interface.


##  Key Highlights

*  Real time voice command recognition
*  Speech synthesis (text-to-speech) for responses
*  Intelligent Google search automation
*  Wake-word detection ("Hey Jarvis")
*  Fast, responsive, and lightweight web app
*  Interactive and animated user interface


## 🛠️ Tech Stack

* Frontend:HTML5, CSS3
* Logic Layer: JavaScript (ES6)
* APIs Used:
             * Web Speech API (SpeechRecognition)
             * Speech Synthesis API


##  Core Functionalities

* Converts voice → text → action
* Executes commands dynamically using JavaScript
* Opens web platforms like:

  * Google
  * YouTube
  * Facebook
* Provides contextual responses (time, date, greetings)
* Handles fallback queries via Google search


##  Supported Voice Commands

| Command Type   | Example                             |
| -------------- | ----------------------------------- |
| Wake Word      | "Hey Jarvis"                        |
| Greetings      | "Hello"                             |
| Search Queries | "What is AI?"                       |
| Navigation     | "Open YouTube"                      |
| Information    | "What is the time?"                 |
| Wikipedia      | "Tell me about Python on Wikipedia" |


##  System Architecture (Simple Flow)

User Voice → Speech Recognition → Command Processing → Action Execution → Voice Response
